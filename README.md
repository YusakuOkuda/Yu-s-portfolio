# ユ | 学習ポートフォリオ

## ディレクトリ構成

```text
outputs/
  index.html   # ページ構造
  styles.css   # ダークテーマの見た目
  script.js    # 表示データ、画面切り替え、資料アップロード表示
  README.md    # 構成メモ
```

## コンポーネント構成

- `Sidebar`: プロフィール、ページナビゲーション、更新ステータス
- `Topbar`: 現在ページのタイトルとサイト説明
- `Home`: 自己紹介、概要、注目成果物
- `ProjectCard`: 成果物カード
- `LearningLog`: 短文学習記録
- `DocumentList`: 資料一覧
- `UploadPanel`: 資料ファイルの一時追加フォーム
